# 纸间 · 我的书架

- 在线书架：`https://alex1122341.github.io/Peak-Life-Game/books/`
- 《西雅图死亡档案》继续调用 `../novel/`，不改变旧阅读器数据和 `seattle-death-file-reader-v1` 键。
- 《蛊真人》只提供书卡、作品信息与阅读研究笔记。第三方小说全文**不随网页公开发布**，需用户在设备上导入自己持有的 EPUB/TXT。
- 以后可以直接点击「＋ 添加小说」导入任意数量新书，无需修改仓库。
- 每本导入书籍独立拥有目录、阅读断点、书签、本机删除功能；阅读器支持字号与主题调整。
- 导入数据存于当前设备 IndexedDB，阅读进度与书签存于 localStorage。没有登录账号、没有跨设备同步；更换设备或清除 Safari 网站数据，需要重新导入原文。
- EPUB 导入采用浏览器原生 `DecompressionStream('deflate-raw')`，目标 iOS Safari 16.4+，不依赖第三方 CDN。
- 未经完整真机测试；建议导入前保留原 EPUB/TXT 文件，尤其在 iOS Safari 私密模式或设备空间不足时。
- `books/notes/` 是原创分析材料，并非原著全文、官方续写或作者声明。

## 后续扩展

动态书库不设固定书位数量。后续可以扩展分类、封面、跨设备同步（需要独立的私有存储与认证），但当前版本均以用户本机隐私为优先。

# 浮世一生 — 古风人生模拟小游戏

[游戏网页（GitHub Pages）](https://alex1122341.github.io/Peak-Life-Game/)

原创、免费、免广告的 iPhone / Android / 桌面浏览器单机小游戏。不是《开局已是巅峰》的官方版本，也不包含原作的受版权保护剧情及美术。

## 游玩内容

- 选择出身和天赋、创建人物，走六条职业路线。
- 每年可执行行动；包含30种随机事件及不同剧情选择。
- 经营产业、升级住宅、收集传家宝、结交人物和培养门客。
- 结婚生子、家族传承、成就解锁与多种人生结局。
- 本地自动存档，并可导出/导入 JSON 存档。
- 无广告、无充值、无外部 API 或统计追踪。

## GitHub Pages 首次启用

该项目只使用根目录的 **index.html**，不需要安装任何依赖。

仓库管理员在 [Settings → Pages](https://github.com/Alex1122341/Peak-Life-Game/settings/pages) 中：

1. Build and deployment → Source 选 **Deploy from a branch**。
2. Branch 选 **main**，Folder 选 **/(root)**，按 **Save**。
3. 在 GitHub Pages 构建完成后访问：https://alex1122341.github.io/Peak-Life-Game/

在 iPhone Safari 打开网址，分享 → 添加到主屏幕，即可像应用一样启动。进度保存在本机 Safari 的网站数据中；清理网站数据前可在游戏「设置 → 导出存档」备份。

## 功能
- iPhone Safari 自适应、章节目录、翻章
- 自动记录每章阅读位置，保存于当前浏览器
- 夜间、米黄、纸白主题；字号和行距调整
- 手动书签；JSON 导出和导入阅读进度
- Service Worker 在线访问后缓存内容供离线访问
- 无需登录、无广告

## 更新章节
1. 在 chapters/ 添加编号 TXT（如 12.txt）。
2. 在 chapters.json 追加章节标题、编号及路径。当前收录第一卷1—50章。
3. 更新 service-worker.js 的缓存版本和章节缓存清单。
4. 提交到 main 后 GitHub Pages 自动发布。

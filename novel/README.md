- 500章分卷折叠目录、上下章切换；
- 自动保存每章阅读断点，退出后继续；保留原有浏览器阅读进度；
- 手动书签、JSON阅读进度导出和导入；
- 夜间、米黄、纸白主题，以及字号和行距调整；
- 默认按需缓存已阅读章节；可在设置中选择**缓存全部500章**离线阅读；
- 无需登录、无广告。跨设备**不自动同步**；清除Safari网站数据可能清除进度。

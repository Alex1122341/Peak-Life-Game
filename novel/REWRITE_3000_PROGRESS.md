## 如何复核

在仓库根目录运行：

```bash
node novel/tools/check-longform.mjs
```

当前为进行中状态，命令会显示已达标及未达标数量。只有在全部改写完成时，下面这条才应通过：

```bash
node novel/tools/check-longform.mjs --strict
```

阅读站点继续保持500章可读，短章暂不删除；已重写章按原文件路径替换，不更改索引ID，因此现有阅读进度与书签的章节关联保持不变。此前的字数统计 `WORD_COUNT.md` 代表旧版本，须在全部重写后重新计算。
